# 🍕 Análise de Dados — Pizzaria

## 📌 Sobre o Projeto

Este projeto consiste em uma análise e tratamento de dados de vendas de uma pizzaria utilizando Python e bibliotecas voltadas para análise de dados.

O objetivo foi realizar a limpeza, organização e preparação da base de dados para futuras análises e visualizações, aplicando conceitos fundamentais de Data Analytics.

---

# 🎯 Objetivos

* Importar e manipular dados utilizando Pandas;
* Identificar e tratar valores nulos;
* Corrigir inconsistências nos dados;
* Ajustar tipos de dados;
* Preparar a base para análises futuras;
* Desenvolver habilidades práticas em análise de dados.

---

# 🛠️ Ferramentas Utilizadas

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* Jupyter Notebook

---

# 📊 Tratamentos Realizados

Durante o projeto foram aplicadas etapas importantes de limpeza e preparação dos dados, como:

* Verificação de tipos de dados;
* Identificação de valores nulos;
* Substituição de valores ausentes pela média;
* Remoção de registros inválidos;
* Conversão de colunas para formato de data;
* Correção de valores negativos;
* Padronização de dados numéricos.
